## 📂 1. File & Directory Operations

| Command | Description |
| :--- | :--- |
| `pwd` | Print working directory (show current path) |
| `ls` | List directory contents |
| `ls -la` | List all files including hidden files with detailed view |
| `cd <dir>` | Change directory |
| `cd ..` | Move up one directory level |
| `mkdir <dir>` | Create a new directory |
| `mkdir -p <dir/sub>` | Create nested directories recursively |
| `rmdir <dir>` | Remove an empty directory |
| `touch <file>` | Create an empty file or update file timestamp |
| `cp <src> <dest>` | Copy files or directories |
| `cp -r <src> <dest>` | Copy directories recursively |
| `mv <src> <dest>` | Move or rename files and directories |
| `rm <file>` | Remove (delete) a file |
| `rm -rf <dir>` | Force remove a directory and its contents recursively |
| `cat <file>` | Concatenate and display file contents |
| `less <file>` | View file contents page by page (scrollable) |
| `more <file>` | Display file contents page by page |
| `head -n <num> <file>` | Output the first <num> lines of a file |
| `tail -n <num> <file>` | Output the last <num> lines of a file |
| `tail -f <file>` | Output appended data as the file grows (live logs) |
| `nano <file>` | Edit a file using the Nano text editor |
| `vim <file>` | Edit a file using the Vim text editor |
| `echo "<text>"` | Print text to the terminal or a file |
| `printf "<text>"` | Format and print data |
| `basename <path>` | Strip directory and suffix from filenames |
